## Dataset Description

The supporting datasets contain data collected from multiple sources, including cameras, radar, AIS, and GNSS.

The dataset includes:

Camera images: visible light camera images stored in .jpg format.
Radar images: radar images stored in .jpg format.
AIS data: AIS information stored in AISData.csv.
GNSS data: navigation information stored in GNSSData.csv.

## Dataset Structure

The directory structure of the released supporting datasets is as follows:

